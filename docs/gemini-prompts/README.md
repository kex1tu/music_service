# Отдельные промпты для Gemini

Каждый файл — самостоятельное задание. Передавай Gemini содержимое одного файла целиком; общий план и предыдущая переписка не обязательны.

| Порядок | Задание | Результат |
|---|---|---|
| 1 | [Имена UTF-8](01-utf8-filenames.md) | Изменения кода и проверки |
| 2 | [Плейлисты Яндекса](02-yandex-playlists.md) | Импорт в предпросмотр и очередь |
| 3 | [Тексты Яндекса](03-yandex-lyrics.md) | Точное получение LRC и fallback |
| 4 | [Короткие превью](04-preview-validation.md) | Проверка существующего механизма, исправления при необходимости |
| 5 | [Обложки](05-cover-handling.md) | Ограничения ресурсов, APIC и оригиналы с fallback |
| 6 | [Прямой источник Яндекса](06-yandex-direct-source-research.md) | Исследовательская записка; реализация отдельно |
| 7 | [UI/UX для ПК и телефонов](07-ui-ux-desktop-mobile.md) | Адаптивная медиатека, навигация, редактор тегов и проверка интерфейса |
| 8 | [Способы загрузки помимо yt-dlp](08-download-methods-research.md) | Сравнение методов, источники и рекомендация; без реализации |
| 9 | [Поиск SoundCloud в выборе источника](09-soundcloud-source-search.md) | Окно поиска, привязка результатов и полноценная пагинация |

Рекомендуемый порядок — сверху вниз. Тексты могут реализовываться и без плейлистов: достаточно идентичности уже поддерживаемого трека Яндекса.

В одном рабочем дереве запускай задания последовательно: они могут затронуть общие модели, downloader, DI, plan.md и PROGRESS.md. Для параллельной работы нужны изолированные копии с корректным исходным состоянием и отдельная интеграция изменений. Наличие worktree само по себе не переносит незакоммиченные правки.

Все задания требуют сохранить существующие изменения. Проверки превью и обложек учитывают уже реализованные функции. Прямое скачивание исследуется отдельно из-за требования AGENTS.md использовать yt-dlp.
